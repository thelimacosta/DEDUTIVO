# 🔎 Dedutivo
### ⬇️ Download
[Clique aqui para jogar](https://github.com/thelimacosta/DEDUTIVO/releases/download/1.0.0/dedutivo.html)

**Dedutivo** é um jogo de investigação com lógica matemática em que você assume o papel de detetive. Analise as pistas, preencha as grades de dedução e descubra quem é o culpado, relacionando suspeitos, objetos e locais.

## Como jogar?

Cada caso apresenta um mistério e um conjunto de pistas matemáticas. Use as informações para descobrir qual suspeito corresponde a cada objeto e ambiente e, por fim, identificar o responsável.

1. Escolha um caso e leia a introdução.
2. Examine as pistas e marque na grade as combinações possíveis ou descartadas.
3. Cruze as informações até chegar a uma conclusão.
4. Faça sua acusação e confira se resolveu o mistério.

## Níveis de dificuldade

O jogo contém quatro níveis, com desafios de dedução progressivamente mais complexos:

- **Aprendiz**
- **Investigador**
- **Perito**
- **Mestre**

## Recursos

- Casos de investigação com personagens, objetos e ambientes.
- Pistas baseadas em operações e relações matemáticas.
- Grades interativas para organizar as deduções.
- Dicas para ajudar quando você ficar preso -> usar uma dica reduz a pontuação do caso.
- Área de anotações para registrar hipóteses, descartes e conclusões.
- Botão para gerar outra versão narrativa do caso.
- Progresso e resultados salvos no navegador.
- Interface adaptável para diferentes tamanhos de tela.
- Ícone próprio do Dedutivo na aba do navegador.

## Tecnologias

- HTML
- CSS
- JavaScript
- `localStorage` para persistência local

>Limpar os dados do navegador ou usar outro navegador/dispositivo pode fazer com que o progresso não esteja disponível. O jogo também possui uma opção para apagar o progresso salvo.

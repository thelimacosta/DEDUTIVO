## O jogo

Um crime aconteceu e cada suspeito esteve num cômodo, com uma arma. As armas têm **peso** e os cômodos têm **número**. Use as pistas, cruze as informações no caderno e descubra **quem**, **com o quê** e **onde**.

As pistas usam aritmética e lógica: negação, conjunção, disjunção, implicação, bicondicional, ou exclusivo, quantificadores e leis de De Morgan.

## Modos

| Modo | O que é |
|---|---|
| **Campanha** | 9 capítulos, um conceito de lógica por capítulo, mais um caso final |
| **Caso do dia** | Um caso novo por dia, o mesmo para todo mundo |
| **Jogo livre** | Casos gerados na hora em 4 níveis, compartilháveis por código |

## Como jogar

Abra o `dedutivo.html` no navegador. Não precisa instalar nada.

Para instalar como app, publique a pasta do app num site com HTTPS (por exemplo, no GitHub Pages) e use a opção "Instalar app" no navegador.
